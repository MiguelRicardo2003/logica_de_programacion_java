Lógica de Programación en Java

Bienvenido/a al repositorio de Lógica de Programación en Java.
Aquí encontrarás una colección completa de ejercicios, ejemplos y proyectos que abarcan desde la lectura básica de datos hasta el uso de estructuras y conceptos más avanzados del lenguaje Java.

Ideal para estudiantes, autodidactas o cualquier persona que quiera fortalecer su pensamiento lógico y aprender programación desde cero con Java.

📘 Contenido del repositorio

Entrada y salida de datos (Scanner, System.out.println)

Operadores aritméticos, lógicos y relacionales

Estructuras condicionales (if, else if, switch)

Bucles (for, while, do while)

Métodos y paso de parámetros

Arreglos y matrices

Cadenas de texto (String)

Clases y objetos (POO básica)

Estructuras de datos básicas (ArrayList, Stack, Queue)

Manejo de archivos (File, FileReader, FileWriter)

Introducción a excepciones (try, catch)

🚀 Objetivos del repositorio

Desarrollar el pensamiento lógico y algorítmico.

Practicar los fundamentos de la programación estructurada y orientada a objetos.

Aplicar bases sólidas para cursos más avanzados de Java, estructuras de datos y algoritmos.

Servir como material educativo o punto de partida para tus propios proyectos.
